# Shivamsh · Robotics & AI (shivamsh)

Hi, I'm **Shivamsh** — a robotics undergraduate building vision-language-action (VLA) models, teleoperation setups, and the tooling around them. This is my GitHub profile; I go by **shivamsh** across the web.

I work at the intersection of robotics and AI: fine-tuning VLAs in simulation (MuJoCo, Isaac Sim), wiring them to real arms (Dobot, SO-101), and building agentic tooling with PyTorch, Transformers and LangGraph. Recent work: Marvin (AI desk-companion robot), Jester (dual-arm teleop @ 50 Hz), VLA Sim (VLA on an SO-101 arm), and DAGger (Rust CVE reachability via graph math).
